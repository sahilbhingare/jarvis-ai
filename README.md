## 🚀 कसे चालवायचे (How to Run)

### पर्याय १: Futuristic Web UI (आयर्न मॅन Arc Reactor HUD)
1. टर्मिनल किंवा PowerShell उघडा आणि या फोल्डरमध्ये जा:
   ```powershell
   cd C:\Users\Server\.gemini\antigravity\scratch\jarvis-ai
   ```
2. वेब सर्व्हर सुरू करा:
   ```powershell
   python app.py
   ```
3. तुमच्या ब्राउझरमध्ये (Chrome किंवा Edge) ही लिंक उघडा:
   👉 **http://127.0.0.1:5000**
4. मायक्रोफोन बटण दाबा आणि बोला, किंवा बॉक्समध्ये टाइप करा!

---

### पर्याय २: डायरेक्ट टर्मिनल / कमांड प्रॉम्प्ट मोड
जर तुम्हाला ब्राउझरशिवाय थेट टर्मिनलमध्ये बोलायचे असेल:
```powershell
python jarvis_cli.py
```

## ⚙️ Google Gemini API Key (ऐच्छिक / Optional)
जार्व्हिस कोणत्याही API Key शिवाय विकिपीडिया, डकडकगो आणि इन-बिल्ट स्मार्ट ज्ञानभांडारावरून सर्व प्रश्नांची उत्तरे देतो.  
परंतु, जर तुम्हाला अजून सखोल आणि अमर्याद बुद्धिमत्ता हवी असेल तर:
1. [Google AI Studio](https://aistudio.google.com) वरून मोफत API Key मिळवा.
2. Web UI मधील उजव्या कोपऱ्यातील **Settings (⚙️)** आयकॉनवर क्लिक करून की सेव्ह करा, किंवा `.env` फाईलमध्ये `GEMINI_API_KEY=your_key` टाका.
